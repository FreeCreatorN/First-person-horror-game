# 参考图版本

模型：PeachwoodSword_Reference.blend，总长约 1.015 米。场景内保留独立的 1.80 米成年男性比例参照集合。

造型：木质细长剑身、太极八卦护手、云纹浮雕与刻线、圆形剑首、深棕交叉缠绳握柄、中国结、木珠、96 条红色丝穗。雕纹是根据参考图重新构造的几何装饰，并非逐像素复刻。

播放：从第 1 帧按空格播放，以剑体几何中点为支点翻转一整圈；第 1 帧为 0°，第 637 帧为 360°，120 帧/秒，约 5.3 秒。高采样率用于细挂绳的运动稳定性，已启用跳帧同步播放。

悬挂结构：只有剑首穿孔处的连接点和固定绳结跟随剑体。上方挂绳采用 18 段定长粒子绳索模拟，受重力、阻尼与剑体碰撞影响；中国结、木珠、穗头作为一个有重量的悬挂组件运动。下方 96 条丝穗继续使用 Blender 布料物理，根部跟随穗头。

保存形式：挂绳与挂件的物理计算结果烘焙为动画曲线，丝穗保留已烘焙的布料缓存。旧刚体世界已禁用；本版没有使用不稳定的刚体链解算结果。它是已完成物理计算的动画版本，不是修改剑体关键帧后即可自动更新的实时绳索插件。

重新计算当前整圈演示：先运行 solve_suspension_rope.py，再运行 bake_full_suspension.py。修改旋转方式、时长或挂点后，需要同步调整绳索求解脚本并重新计算，不能只删除布料缓存。未配置与人体或其他外部场景的碰撞。
Steam Blender 连接：已安装 Codex Local Blender Bridge，启用后可在 3D 视图右侧 N 面板 → Codex 查看状态。连接仅监听 127.0.0.1:9876，支持当前电脑上的场景查询和脚本操作。多个 Blender 窗口同时打开时，只有最先占用端口的窗口连接；可在面板里断开，再在另一个窗口连接。此连接可执行 Blender Python，仅用于本机可信工作流程。

当前 Codex 会话通过本机连接脚本控制 Blender；这不是已注册到 Codex 工具列表中的 MCP 服务器。

模型用于 Blender；导入 Unreal 后的运行时物理与材质烘焙需要另行制作。

# 空柜台规划组件

替换目标保持 `/Game/Yastars/Mesh/ShopCounterPlan/BP_ShopCounterPlan`。

规划书八类组件对应蓝图的八个顶层组件。两组推拉门各保留左右独立门片，因此共有十个静态网格。

| 规划书部件 | 蓝图组件 | 独立网格 |
|---|---|---|
| 玻璃顶板 | GlassTop | SM_ShopCounterPlan_GlassTop |
| 玻璃围挡 | GlassSurround | SM_ShopCounterPlan_GlassSurround |
| 金属框架 | MetalFrame | SM_ShopCounterPlan_MetalFrame |
| 展示层板 | DisplayShelf | SM_ShopCounterPlan_DisplayShelf |
| 木质柜体（储物） | Body | SM_ShopCounterPlan_Body |
| 推拉柜门 | WoodSlidingDoors | WoodDoorLeft / WoodDoorRight |
| 推拉玻璃门 | GlassSlidingDoors | GlassDoorLeft / GlassDoorRight |
| 内部层板 | InteriorShelf | SM_ShopCounterPlan_InteriorShelf |

四扇门沿各自门组的本地X轴平移。门组自身的位置、旋转和缩放保持单位变换。源 `Exports/export_report.json` 的闭合坐标、打开行程保持厘米单位，可用于项目蓝图里的 `Move Component To`。当前更新完成独立模型装配，不新增交互按键或开关事件。

原先的合并玻璃组件 FixedGlass 被拆开。旧合并网格仅在没有资产引用时清理，如仍有用户内容引用则保留为停用兼容资产。更新前的原有资产在 SourceArt/ShopCounterPlan/Archives 下有可恢复备份。

# 小卖部柜台规划版

导入目标为 `/Game/Yastars/Mesh/ShopCounterPlan`。与此前的玻璃柜分开保存。

当前版本为空柜台，`BP_ShopCounterPlan` 顶层对应规划书八类组件，包含十个独立静态网格。玻璃顶板为 `GlassTop`，固定围挡为 `GlassSurround`，分别建模。`WoodSlidingDoors` 组下挂 `WoodDoorLeft`、`WoodDoorRight`，`GlassSlidingDoors` 组下挂 `GlassDoorLeft`、`GlassDoorRight`，四扇门均可独立移动。其他四类为 `Body`、`MetalFrame`、`DisplayShelf`、`InteriorShelf`。

门的闭合坐标和行程以 `Exports/export_report.json` 中 `doors` 数据为准，UE单位为厘米。所有门沿父组本地X轴移动，左右门使用错开的两条轨道。父组位置和旋转为零、缩放为一。

此蓝图仅完成部件装配，不含开关事件或交互按键。要实现推拉，在事件图为门添加 `Move Component To`，组件使用对应的门，闭合终点为 `closed_ue_cm`，打开终点为该坐标的 X 加 `travel_cm`，旋转为零，建议时长 0.55 秒并勾选缓入、缓出。事件可接项目自己的交互系统，不依赖 Python 运行游戏。

木材和金属共用一套 BaseColor 与 ORM 图。ORM 的 R/G/B 分别为环境遮蔽、粗糙度、金属度。玻璃独立材质参数 `GlassOpacity`、`GlassRoughness`、`GlassTint`、`GlassIOR` 可外部修改；没有自发光或灯光组件。

在所有UE编辑器关闭时运行 `run_replace_empty.ps1`，会先备份当前目录资产，再在原路径更新，并启动第二次只读检查。组装蓝图保持同一个资产路径。脚本只保存柜台目录中的资产；旧合并玻璃在没有引用时清理，若有外部引用则保留为非组装的旧资产。最新报告为 `empty_final_verification.json`，旧资产备份位置由报告中的 `backup_directory` 记录。

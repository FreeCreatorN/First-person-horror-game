# 小卖铺柜台规划版

打开 `ShopCounterPlan.blend`。当前是空柜台，尺寸约196×62×109厘米，2640个三角面。模型只保留一个场景，商品、罐子和包装标签已移除。

模型与UE蓝图均按规划书组织为八类组件。

| 规划书组件 | 对应网格或子件 |
|---|---|
| 玻璃顶板 | GlassTop |
| 玻璃围挡 | GlassSurround |
| 金属框架 | MetalFrame |
| 展示层板 | DisplayShelf |
| 木质柜体（储物） | Body |
| 推拉柜门 | WoodDoorLeft、WoodDoorRight |
| 推拉玻璃门 | GlassDoorLeft、GlassDoorRight |
| 内部层板 | InteriorShelf |

两类门各有左右两叶，因此八类组件共导出十个独立网格。每个门组的父级位置、旋转均为零，缩放为一。

`ShopCounterPlan_Front.png` 和 `ShopCounterPlan_RearOpen.png` 是实际模型渲染。预览灯光、地面和相机在独立预览集合中。

UE目录为 `/Game/Yastars/Mesh/ShopCounterPlan`，组装资产为 `BP_ShopCounterPlan`，在此原路径更新旧版本。四扇门是独立可移动组件，沿组件父级的本地X方向平移。玻璃使用独立透明材质，粗糙度、透明度和色调有可调参数。

当前UE蓝图完成模型装配，尚未接入开关事件或交互按键。可用 `Move Component To` 对相应门组件进行移动，建议0.55秒，缓入缓出。闭合与打开坐标如下，单位厘米。

| 门组件 | 关闭位置XYZ | 打开位置XYZ |
|---|---|---|
| WoodDoorLeft | -46.3, -23.8, 14.7 | 46.3, -23.8, 14.7 |
| WoodDoorRight | 46.3, -27.2, 14.7 | -46.3, -27.2, 14.7 |
| GlassDoorLeft | -46.6, -25.95, 77 | 46.6, -25.95, 77 |
| GlassDoorRight | 46.6, -28.85, 77 | -46.6, -28.85, 77 |

UE导出文件只包含这十个网格及独立碰撞。预览灯光、相机和地面位于独立预览集合中，不作为柜台组件导入。空柜台拆分记录在 `UE/empty_final_verification.json`；侧边包条和接缝修复的最新核对结果在 `SideFix/UE/side_fresh_report.json`。

# 立式饮料冰柜

UE目录为 `/Game/Yastars/Mesh/BeverageDisplayFridge`，组装蓝图为 `BP_BeverageDisplayFridge`。

规划书九类部件对应十六个独立网格。

| 规划类别 | 组件 |
|---|---|
| 顶部灯箱与顶盖 | TopLightbox |
| 玻璃门 | GlassDoor |
| 门把手 | DoorHandle |
| 门框 | DoorFrame |
| 内部层板 | Shelves → Shelf01至Shelf05 |
| 内胆 | InnerLiner |
| 外壳主体 | OuterBody |
| 散热格栅 | VentGrille |
| 底座与底脚 | BaseFeet → FootFL、FootFR、FootRL、FootRR |

门的玻璃、门框、把手都挂在 `DoorHinge` 下，三个网格原点一致，子组件相对位置为零。铰链位置按导出清单中 `doors.main.closed_ue_cm` 设置。这样转动 `DoorHinge`，整扇门会一起转动。因为三个门部件共享一组铰链，蓝图实际有七个根分支，对应规划书的九类，而非九个互不相连的根组件。

蓝图已完成装配，尚未接入交互按键或开门事件。接项目交互时，可给 `DoorHinge` 使用 `Set Relative Rotation` 或时间轴；关闭Yaw为0，打开Yaw以 `doors.main.open_yaw_deg` 为准。不要只转动玻璃或把手。

所有网格都有独立简化碰撞。玻璃与烤漆、金属的材质槽分离。灯箱若使用 `M_Fridge_Sign`，其 `SignEmissionStrength` 默认0.2，可在动态材质实例中改为0关闭发光。灯箱材质不创建点光源或聚光灯。

当前UE已打开时，通过Output Log执行 `run_live.py`。它只创建本目录的资产，不更改或保存当前关卡。UE都关闭时可运行 `run_exclusive.ps1`，会导入并另开只读编辑器重新加载检查。结果写入 `final_verification.json`。

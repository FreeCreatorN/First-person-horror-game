# 纸箱模型组

按参考图制作五种基础外观与三种印刷变体。主体参考尺寸为60×40×30厘米。

| 类型 | UE资产 | 三角面 |
|---|---|---:|
| A 常规封箱 | SM_CardboardBox_A_Sealed | 296 |
| B 四盖开口箱 | BP_CardboardBox_B_Open | 268 |
| C 带提手储物箱 | BP_CardboardBox_C_Storage | 480 |
| D 压皱破旧箱 | SM_CardboardBox_D_Damaged | 296 |
| E 双箱堆叠组合 | SM_CardboardBox_E_Stack | 592 |
| F 绿色蔬果箱 | SM_CardboardBox_F_Fruit | 432 |
| G 浅色矿泉水箱 | SM_CardboardBox_G_Water | 432 |
| H 红色方便面箱 | SM_CardboardBox_H_Noodles | 432 |

UE目录：`/Game/Yastars/Mesh/CardboardBoxSet`。
源文件：`CardboardBoxSet.blend`。源场景中各类型分开摆放；FBX都以自己的原点导出，不带展示间距。

## 分件与操作

B开口箱为箱体和四片箱盖，共五个独立静态网格。装配蓝图已按箱口的折线设置各盖片原点。
C储物箱为箱体与独立盖子，共两个静态网格。蓝图里的C_Lid可单独沿Z轴抬起。
C前后提手孔、F/G/H左右侧提手孔均为实际开孔。
箱壁与盖子厚4毫米，B盖片厚3毫米。

这组资产交付静态外观和可单独移动的组件，没有绑定开箱按键、动画或游戏交互。
E为合并好的静态堆叠外观；需要分别移动箱子时可以使用A等单箱资产自行摆放。

所有网格带简化碰撞；开口箱与储物箱使用多块凸包保持内部空间。
简化碰撞不刻画提手孔，近距离手指交互时可另设精细查询碰撞。

## 材质

五组2048² BaseColor/ORM，另有共享2048²纤维法线。
普通内衬与胶带使用共享512²贴图。
ORM：红通道AO、绿通道粗糙度、蓝通道金属度（纸箱为0）。
源法线为OpenGL正Y；UE导入时翻转绿通道。

贴图文字、运输标记和图形为本项目程序绘制的原创素材，没有使用品牌商标。
预览的地面、标注、相机与灯光都位于_PreviewOnly集合，不导入UE资产。

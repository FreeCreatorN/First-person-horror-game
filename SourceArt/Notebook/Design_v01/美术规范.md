# 笔记本整体美术方案 v01

日期：2026-10-30。阶段：整体视觉概念，供后续封面、笔记本界面及相关美术内容统一参考。

## 设计依据

游戏主体通过笔记本展开，笔记本承担游戏封面和主要内容载体的识别。用户提供的页面截图是功能排版参考；本方案设计完整笔记本的外观及界面气质。

- `Notebook_OverallStyle_v01.png`：本次整体设计稿，包含合拢外观、竖版单页界面、装订细节、相纸与笔迹示意。
- `User_PageLayout_Reference.png`：用户提供的页面原图，是页面结构的依据。
- 现有 `SourceArt/KraftBook/KraftBook_Preview.png`：本次书本体量与牛皮纸质感的形体参考。
- 现有相机、笔、横线纸和白边相纸提供日常物件的材质语境。

图中“手记”为封面排版占位字，不代表已经确定的游戏名称；照片及旁注仅演示视觉关系，不构成剧情设定。此目录中的图片是概念设计图，不是已导入的 UE 资源或可直接使用的完整 UI 切图。

## 核心识别

一本长期随身使用的私人笔记本。自然牛皮纸包覆硬封面，深炭绿织物包脊，米白纸芯，褪色暗红布书签。识别依靠书本轮廓、布脊与纸标签的组合。

气质：生活化、安静、克制、可触摸；环境可以昏暗，纸面的阅读区始终清晰。

## 封面与装订

- 竖版硬封面，轻微圆角，保留硬板、包纸和书芯之间的厚度差。
- 炭绿布脊约占封面宽度的十分之一，沿书脊与铰接折线自然包覆；比例以设计图为视觉参考。
- 上半部设置一张横向米白纸标签，细双线框配少量手写字；后续正式名称在此排版。
- 牛皮纸有纤维、轻微压痕和手指摩擦后的光泽变化；标签边缘略旧。
- 书芯呈暖灰米白，多层纸边有微小高低差。打开时左侧出现窄书沟，封皮从页边略微露出。
- 暗红书签从书本底部自然伸出，与页内竖线及交互强调色呼应。
- 本次未重新定义实物尺寸，也未修改现有书本几何或翻页动画。

## 页面与排版

保留用户原图的竖版单页结构。现有代码默认纸面为 700×1000、行距 24，后续制作时以实际页面坐标和用户原图校准，不从概念图反推精确坐标。

- 页面宽高比目标约 0.70；内容区保持平整，装订边附近可轻微弯曲。
- 底纸为旧米白，细纤维与浅色差低于横线和文字的对比度；纸中央比边缘干净。
- 横线采用褪色灰蓝；右侧约四分之三宽度处的竖线采用暗红，位置沿用用户原图。
- 右上保留关闭；底部左、右分别保留上一页与下一页；页码居中。
- 书脊、书口、露出的封皮和接触阴影形成完整书本的层次，正文区有充足留白。

## 控件与状态

箭头、关闭符号、页码和控件文字统一使用清晰的深炭色印记。轻薄纸片底或局部浅色底可以用于衬托，避免遮挡横线与正文。

后续状态表现建议：正常为深炭色；悬停或键盘选中用暗红加深和短下划线；按下用轻微压印反馈；不可翻页时降低墨色并保留轮廓。以上是视觉状态规范，尚未接入交互。

控件位置服从现有页面结构，最终字号与点击范围以游戏内可读性和实际操作核验。

## 照片、正文与批注

- 照片沿用白边相纸语言：相纸略亮于底纸，图像与白边有清晰区分，底白边可承载短题注。
- 照片允许小角度偏转和薄接触阴影；旧半透明胶带作为稀疏的固定细节使用。
- 正文首先保证中文清晰可读；手写感适合标题和短批注，避免把长段正文做成难以辨认的花体。
- 照片、整圈白边和必要阴影都需预留文字间隔，不能只避让图像中心。现有代码使用方形照片避让区，落地时需校准到完整外轮廓。
- 照片内容、笔迹及题注作为独立内容变化；底纸、线条与材料保持一致。

## 颜色与材料

以下为制作时的起始色值，实际画面需结合灯光和材质校准；并非对概念图每个像素的精确取样。

| 元素 | 起始颜色 | 材质重点 |
| --- | --- | --- |
| 牛皮纸封面 | `#A88C65` | 纸纤维、压痕、轻微磨亮 |
| 深炭绿布脊 | `#303B36` | 细织纹、折线处少量起毛 |
| 内页底纸 | `#E9E2D1` | 暖米白、低对比细纤维 |

| 灰蓝横线 | `#A0AAA8` | 细而轻，弱于正文 |
| 竖线与书签 | `#7B4140` | 褪色暗红，作为定位色 |

## 磨损规则

磨损集中于封皮外角、布脊折线、书签末端和右下翻页角；纸张边缘比中央略深。控制局部细毛边、手渍、标签翘角的数量和强度，使相邻结构具有一致的使用程度。

大面积书写区保持干净。后续照片、便条或印记应服从同一套纸张、墨色与接触阴影关系，避免不断叠加装饰而淹没正文。

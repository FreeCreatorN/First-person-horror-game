# 冰柜（冷冻展示柜）

`IceCreamFreezer.blend` 是可编辑源文件。模型约130×70×88厘米，3288个三角面，按规划书组织为六类、十一个独立网格。

| 规划类别 | 独立部件 |
|---|---|
| 外壳柜体 | Body，包含散热口和控制面板 |
| 上框架与滑轨 | TopFrame |
| 玻璃滑门 | GlassDoorLeft、GlassDoorRight |
| 内胆 | Liner |
| 内部篮筐 | BasketLeft、BasketRight |
| 万向轮 | WheelFL、WheelFR、WheelRL、WheelRR |

柜内没有商品。两个篮筐有挂钩承托在封边上，轮子接地。篮筐和脚轮原点分别位于篮筐底部中心、脚轮安装板中心，便于单独放置与控制。

Blender时间轴第1、150帧全部关闭；第34帧左门打开，第98帧右门打开。两扇玻璃均为弧面实厚网格，沿本地X轴在不同高度的双轨上滑动。

UE路径为 `/Game/Yastars/Mesh/IceCreamFreezer`，组装蓝图为 `BP_IceCreamFreezer`。左右门、两个篮筐和四个轮子均为独立可移动组件。玻璃透明度、粗糙度、色调可通过材质参数调整。交互按键与开关事件尚未接入，可在项目中使用 `Move Component To`，按导出清单中给定的闭合位置和行程控制滑门。

预览灯光、相机和地面在单独集合中，未导入UE。所有导入网格均有简化碰撞。柜体、框架、内胆、玻璃与轮组之间未发现共面重叠；篮筐线材在焊接接头处保留制造连接。

`IceCreamFreezer_Front.png` 和 `IceCreamFreezer_Open.png` 是实际模型渲染。导入与材质、尺寸、组件层级、碰撞核对结果在 `UE/final_verification.json`。本次在已有编辑器中完成导入，未另开编辑器进行独立重新加载测试。

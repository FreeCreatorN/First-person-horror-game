# 冰柜（冷冻展示柜）

UE目标目录为 `/Game/Yastars/Mesh/IceCreamFreezer`，组装蓝图为 `BP_IceCreamFreezer`。

顶层按规划书组织为六类。

| 类别 | 组件 |
|---|---|
| 外壳柜体 | Body |
| 上框架与滑轨 | TopFrame |
| 玻璃滑门 | SlidingGlassDoors → GlassDoorLeft、GlassDoorRight |
| 内胆 | Liner |
| 内部篮筐 | Baskets → BasketLeft、BasketRight |
| 万向轮 | Wheels → WheelFL、WheelFR、WheelRL、WheelRR |

六类组件共十一个独立静态网格。各父组位置、旋转为零，缩放为一。玻璃与金属框架使用独立材质槽，透明度、粗糙度、色调、折射参数可通过动态材质实例修改。所有组件具备导出时指定的简化碰撞，不含灯光和自发光。

左右玻璃门可沿组的本地X方向独立移动。闭合位置见 `Exports/export_report.json` 的 `doors.*.closed_ue_cm`，打开位置在该坐标X上加 `travel_cm`。单位为厘米。蓝图完成模型装配，交互按键和开关事件需接入项目逻辑；可用 `Move Component To` 驱动门组件，建议0.5秒并缓入缓出。

在所有UE编辑器关闭时运行 `run_exclusive.ps1`，会先核对导出文件，创建本目录资产，再另开一次只读编辑器重新加载验证。若UE已打开，脚本会停止，避免并发写入。也可从当前UE的Python Output Log执行 `run_live.py`，它只导入新资产，不改变或保存当前关卡。

导入只针对这个新目录，不覆盖之前柜台、UI或地图。最新验证结果为 `final_verification.json`。

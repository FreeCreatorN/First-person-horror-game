# 旧布艺三人沙发

依据用户提供的三人位软包沙发规划图制作，Blender MCP 完成建模与分件，CLI-Anything 用于实际源文件的预览检查。

## 尺寸与部件

整体宽 230 cm、深 95 cm、高 85 cm。组装蓝图的原点为整体底部中心。LOD0 共 13,604 个三角面，包含包边线；没有外露木架或金属框架。

共 15 个独立静态网格：

| 名称 | 部件 | 数量 |
|---|---|---:|
| SM_Sofa_Base | 全包布底座与后背支撑，含扶手让位区域 | 1 |
| SM_Sofa_Arm_L / R | 左右圆鼓软包扶手 | 2 |
| SM_Sofa_Seat_01 / 02 / 03 | 带压痕、包边的坐垫 | 3 |
| SM_Sofa_Back_01 / 02 / 03 | 后倾、鼓起的靠背软包 | 3 |
| SM_Sofa_Foot_FL / FR / BL / BR | 低矮隐藏脚 | 4 |
| SM_Sofa_Pillow_L / R | 格纹抱枕 | 2 |

布料包含旧化色差、细织纹和粗糙度变化。软包轮廓有轻微不规则起伏，包边贴合实际表面。软包支撑接触保留少量压入量，详细数值与原因记录在几何检查报告中。

## UE5 中使用

内容路径为 `/Game/Yastars/Mesh/ThreeSeatSofa`。

把 `BP_ThreeSeatSofa` 拖入关卡即可得到完整沙发。15 个网格部件保持独立，位置和尺寸已组装好。两个抱枕可以单独隐藏或删除其组件。

组件设为可移动，方便后续在自己的蓝图中控制。当前蓝图只负责组装，未添加坐下、拖动物件、布料模拟或其他游戏交互事件。

网格带有简化凸碰撞，整组共 17 个碰撞体。未默认开启物理模拟。对普通静态场景布置，可按自己项目需要把组件的可移动性改为静态。

UE 网格包含 LOD0 至 LOD3。LOD0 保留原模型；远处级别由 UE 简化生成。整组实际三角面数量为：

| 级别 | 三角面 |
|---|---:|
| LOD0 | 13,604 |
| LOD1 | 6,918 |
| LOD2 | 3,986 |
| LOD3 | 1,886 |

使用默认自动距离切换即可，也可以在网格编辑器中调整屏幕尺寸阈值。各网格的检查记录见 `UE/final_verification.json`。

## 材质

三个独立 2K PBR 材质组：

- `M_Sofa_Fabric`：旧棕色主布料。
- `M_Sofa_Plaid`：灰棕格纹抱枕。
- `M_Sofa_Underside`：深灰底布。

每组各有 BaseColor、Normal、ORM，共 9 张贴图。BaseColor 使用 sRGB，ORM 的 R/G/B 分别为 AO/粗糙度/金属度，按线性数据读取。法线源图为 OpenGL +Y，UE 中已翻转绿色通道。

包边与脚另有独立材质。模型没有发光材质；检查效果用的灯光、地面和相机只存在于 Blender 中。

## 文件

- `ThreeSeatSofa.blend`：包含打包贴图的 Blender 源文件。
- `Sofa_Hero.png`、`Sofa_Rear.png`、`Sofa_Front.png`：源场景实际渲染图。
- `Exports/`：独立网格 FBX、贴图与导出清单。
- `Textures/SofaMaterialManifest.json`：材质与贴图规格。
- `QA/sofa_geometry_audit.json`：尺寸、闭合、面朝向、接触及重面检查记录。
- `UE/fresh_editor_verification.json`：保存后重新加载的验证记录。
- `current_delivery.json`：交付数量、文件位置与验证索引。

# 旧旅馆营业配件

15种原创Blender灰盒配件，独立于既有酒店建筑源。打开 `OldTownHotelOperationsKit.blend` 可查看按网格排开的模型；网格位置仅用于展示，FBX均从原点导出。

源几何单位为米，清单及UE摆放单位为厘米。每个FBX已独立重导，核对尺寸、边界与原点；`ImportManifest.json`记录实际边界和文件指纹。转盘电话的侧边卷线提供不对称Y边界，用于验证UE导入方向。

UE旧版FBX导入会反转Y轴，本轮在新物件实例上还原方向；碰撞使用正向、单独的盒体。小件装饰不承担碰撞。请勿重新导出后仅替换源文件：重新导出会改变文件指纹，需要同步重导UE及更新验证记录。

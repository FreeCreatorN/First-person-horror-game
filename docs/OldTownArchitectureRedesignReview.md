# 老城建筑重设计 V4：酒店已批准实施

2026-10-08。用户明确批准按V4实施酒店，并要求楼上对应调整。四层酒店已按大门正中、前台对门、办公室全左、安全梯右上、公共厕所右下的方案完成并通过重载验证，实施结果见 `docs/OldTownHotelV4Progress.md`。住宅沿用V2审查方案，尚未在本次酒店实施中改变；V2/V3图册保留为历史。

主楼长70m，正中为s35。大厅段改为s23–47、宽24m，因此局部中轴x12对应整栋s35；2m大门、门斗及4.2m前台中心都在该轴，柜台正面朝入口。门斗改为4×2.2m，使用滑门，门后至前台前缘留2.2m横向公共通道；前场左右分支绕门斗，通向两翼共有走廊。

三间办公室全部集中大厅左侧：值班/员工9.24㎡、管理/弱电9.24㎡、前台办公室11.76㎡。竖向成排，各门朝右，接净1.4m员工通道。前台后工作带y5.6–7.0净1.4m，向左通员工区。右后翼仅清/污布草、更衣、员工WC、设备及收货整理区，没有办公室；上层配送仍共用客梯。

安全梯移到图纸右上（酒店后右），净5.88×3.2m，外包6.28×3.6m；两跑各净1.4m、两端平台各1.4m。左端为同层平台，左墙入口与首层后墙出口都接该平台；右端为半层转台，不开室外门。上层没有后墙出口。电梯移到后场偏左，净3×3m，门朝右侧公共梯厅；与安全梯逐层同轴。原南北两端楼梯保留。

右下公共厕所净5.6×3.2m，侧向进入，设两独立厕位。洗手盆放在左侧入口缓冲的后部，厕位前墙与门位在y4.0，入口下方y2.6–3.94留约1.34m连续共享通道；不再让洗手盆挡住第二厕位。厕所外侧前场的2.2m共有走廊保留。

后侧出口接续为有条件的新提案：02页右下画出后出口→后侧预留通道→绕北楼端→临街前场整段虚线。现有资料没有证明酒店后侧与楼端用地可通行，仍需场地复核。图中不宣称这条路线已在UE连通；不可在未核实情况下直接实施为已成立的室外疏散路线。

酒店仍为70×10.4m、四层。24m大厅段内净236㎡，扣办公室围护34.32㎡、梯间在厅内21.352㎡、井道10.88㎡、公共厕所20.88㎡、门斗隔墙约0.96㎡，公共净区估算147.61㎡，图标约148㎡；包含柜台、候客与门斗。候客为后左6座、后梯厅2座，共8座。两单椅分置会客区入口两侧，茶几缩到0.6m宽，两旁各留0.6m；中间入口留空。早餐/茶厅24座，行李室继续取消。面积以后续结构图为准。

上三层核心改为s30–47、宽17m。左翼24m排五房，开间4.8m，房内4.6×7.6m约35.0㎡；右翼17m排四房，开间4.25m，房内4.05×7.6m约30.8㎡，均含独立卫浴。每层9房，总27房，201–209、301–309、401–409。右房卫浴、衣柜、窗桌及床均按较窄模数适配；前侧2.2m公共走廊连续，不必穿中部梯间去另一端。

住宅按实际地块区分：后排60m连排划成四个15m单元；每个单元楼梯由多户共用，住户门开向共有平台。15×10m为典型详图，邻段9–11m进深另需适配；现有3–5层分别保留单元标高，不直接打通不同标高楼板。主街窄栋采用小户出租；最窄地块可每层一户，但整座楼仍是多户共用楼梯。

本轮检查实际PNG、PDF及坐标：用户五项布局落实；修复洗手盆挡厕位通道、会客单椅横封入口、茶几过宽和图面文字交叠。UE活动地图、统一证据入口及V2/V3 PDF指纹未变。验证针对方案图，不代表UE运行时、碰撞、结构或消防审查已完成。

待审重点为中轴接待、左侧办公室与右侧梯厕。确认后还需复核后侧出口室外用地、原柱梁、实际层高/级数、楼板洞口、门型/防火构造和完整疏散距离，再建模。03页前场只画局部，图幅边界不代表退线深度。

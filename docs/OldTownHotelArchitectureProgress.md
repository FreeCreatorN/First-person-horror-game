# 旧旅馆建筑设计与实现

定位为停业后的老招待所：保留旧城外观，以泛黄墙面、绿色墙裙、旧木家具、房号牌和少数仍亮的日光灯呈现废弃感。当前设计不是空房间加床；先建立接待、住宿、卫浴、后勤和通行关系，再做旧化。

建筑沿用 70.0×10.4m、四层外壳。街侧长廊净宽1.8m，两端独立楼梯连接各层，并分别向室外开门。首层有101、102两间加宽门的双人房；二至四层各13间，总计41间。标准房净包络约31㎡，其中卫浴约5.06㎡；面积包括独立卫生间，不是卧室净面积。

| 区域 | 实际设计 |
|---|---|
| 首层接待 | 入口南侧前台、背墙钥匙格和招牌；柜台退出电梯井投影 |
| 首层公共 | 会客厅、茶餐区、分隔备餐间、公共卫生间 |
| 首层后勤 | 办公室、员工卫生间；污布草从走廊进，清洁布草从办公室独立进 |
| 客房层 | 独立卫浴、衣柜、床和窗边书桌；中央电梯前室和封闭布草间 |
| 交通 | 南北封闭折返楼梯、真实楼板洞口、出口门槛；外门向室外开启 |
| 湿区 | 客房卫浴和管井逐层对齐，首层备餐布置在东侧干区 |
| 旧化 | 绿色墙裙及漆面缺失、旧木门和门牌、泛黄卫生洁具、磨砂淋浴屏、4处残存单面日光灯 |

设计依据和案例记录在 `Saved/CodexOutputs/HotelArchitecture_20261005/ResearchSources.md`；它是调研记录，其中的24房草案已由41房最终布局替代。当前平面图是同目录 `DesignPlan.png`，实际数据为 `ArchitecturePlan.json`。Blender源模型和49个配件在 `SourceArt/OldTownHotelArchitecture_20261005`，UE配件仅写入本轮专用资产目录。

实际验证包括房间/卫浴/公共后勤路线、双梯、外门开启方向、门关闭时的真实阻挡、家具与墙体/井道交叠，以及既有街道对象和共享素材保留。最终通过项、地图指纹和截图以本轮 `FinalReview.json` 为准；旧阶段的截图和24房审计属于历史证据。

保留700cm机动车道、180cm人行道、已开放窄巷及已调整的单向路灯。电梯目前是封闭井道和落地门的建筑模型；门窗尚未接入玩家输入，未完成运行时玩家巡游和电梯运行功能。
